# 🎮 PartyArcade

スマホで遊ぶ、友達8人までの対戦ミニゲーム集です。
ルームを作って、4けたのルームIDを友達に教えれば、すぐに遊べます。

---

## 遊び方

1. なまえを入力する。
2. 1人が「**ルームを作る**」を押す(その人が管理者になる)。
3. ほかの人は、4けたの**ルームID**を入れて「**入室する**」。最大8人まで。
4. 管理者がロビーでモードを決めて「**ゲームスタート**」。
5. 各ゲームの前に5秒のカウントダウンがあり、そこでルールが出る。
6. 全員が終わると結果が出る。

### モード

| モード | 内容 |
| --- | --- |
| **アーケード** | ランダムなゲームを4〜8ラウンド続けて遊ぶ。順位ポイントの合計で優勝を決める |
| **ソロゲーム** | 選んだゲームを1回だけ、みんなで遊ぶ。ポイントは付かない |
| **練習モード** | ホームから、1人で好きなゲームを遊べる。記録は保存されない |

### ボーナス(アーケード)

- **ダブルアップ**: ランダムな1ラウンドのポイントが2倍。そのゲームの開始前に発表される。
- **ファイナルアップ**: 最終ラウンドのポイントが2倍。

### ポイント

| 順位 | 1位 | 2位 | 3位 | 4位 | 5位 | 6位 | 7位 | 8位 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ポイント | 10 | 8 | 6 | 5 | 4 | 3 | 2 | 1 |

- 同じ記録は同じ順位。失敗・未提出は0ポイント。

### 管理者ができること

- ロビーで、ほかの人を「外す」「管理者にする」。
- 管理者が退出すると、いちばん早く入った人が次の管理者になる。

## 困ったとき

- **ゲームがずれて見える/新しいゲームが出ない** → ブラウザのタブを一度閉じて、開き直す(古いファイルが残っていることがあります)。全員そろえてください。
- **回線が切れた** → 再読み込みすれば、同じルームに戻れます。
- **ラウンドが進まない** → ゲーム開始から25秒たつと、自動で結果に進みます(終わっていない人は0ポイント)。
- 作ってから12時間たったルームは、自動で消えます。

## セットアップ(管理する人向け)

### 1. Firebase

1. [Firebase](https://console.firebase.google.com/) でプロジェクトを作り、**Realtime Database** を作成する。
2. データベースのルールを次のようにする(友達用なので、だれでも読み書きできる設定)。

```json
{
  "rules": {
    "minigame-rooms": {
      ".read": true,
      ".write": true,
      ".indexOn": ["createdAt"]
    }
  }
}
```

3. プロジェクトの設定から、ウェブアプリの `firebaseConfig` をコピーして、`core.js` の一番上に貼る。

### 2. GitHub Pages

1. このリポジトリに、次のファイルを置く(ファイル名はすべて小文字)。
   - `index.html` `games.js` `games2.js` `core.js` `battle.js`
2. リポジトリの **Settings → Pages** で、ブランチ(main)を選んで公開する。
3. 表示されたURLを友達に送る。

### ファイルの役割

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の枠とデザイン。スクリプトを読み込む |
| `games.js` | ゲーム1〜9と、共通の道具 |
| `games2.js` | ゲーム10〜14 |
| `core.js` | Firebaseの設定・ホーム・練習モード・ルームの作成と入室 |
| `battle.js` | ロビー・ラウンドの進行・結果 |

## ゲームの追加方法

1. `games2.js` の最後に、`GAMES.push({...})` と `play` 関数を書く。

```js
GAMES.push({
  id: 'xxx', title: 'ゲーム名',
  desc: 'ルール説明(カウントダウン中に表示)',
  lowerBetter: true,          // true=小さい値が上位 / false=大きい値が上位
  miss: 99,                   // 失敗のときの値
  isMiss: v => v >= 99,       // true なら0ポイント
  fmt: (v, x) => v + '点',    // 結果の表示
  play: playXxx
});

function playXxx(stage, round, submit) {
  const game = GAMES.find(g => g.id === 'xxx');
  countdown(stage, game, round, () => {
    stage.innerHTML = '...';  // ゲーム画面
    // 終わったら submit(値) を1回だけ呼ぶ
  });
}
```

2. 全員に同じ問題を出すときは、`seededRng(Math.round(round.delay * 1000))` で乱数を作る。
3. 制限時間は、開始から18秒以内にする。
4. `index.html` の `?v=` の数字を上げる(キャッシュ対策)。
